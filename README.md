# 星图机 · ziquan-starmap

紫圈人物关系星图：把圈中人物、彼此关系与事件时间轴做成一张可交互的星图。

- **星图**：人物是星，关系是连线，可拖动、缩放、点选查看人物卡。
- **人物页**：印象、简介（带出处标注）、语录、熟悉度。
- **事件轴**：按时间排列的事件列表，与人物互相跳转。

## 结构

| 文件 | 说明 |
|---|---|
| `index.html` | 页面骨架 |
| `app.js` | 星图渲染（Three.js）、人物页与事件轴逻辑 |
| `style.css` | 样式 |
| `data/nodes.json` | 人物数据 |
| `data/edges.json` | 关系连线 |
| `data/events.json` | 事件数据 |

## 运行

纯静态站点，把本目录挂到任意静态服务器（或直接以文件方式经本地服务器打开）即可，无构建步骤。
